# Mi Entreno para Android

Esta aplicación abre Mi Entreno en una pestaña segura de Chrome (Custom Tab).
Así conserva el inicio de sesión de ChatGPT del usuario y accede a la misma
base de datos que la versión web.

## Uso

1. Instala `mi-entreno.apk` en Android.
2. Abre **Mi Entreno** desde el icono.
3. Inicia sesión con ChatGPT la primera vez, si Chrome aún no dispone de la
   sesión.

La APK se compila automáticamente con el flujo de GitHub Actions incluido en
este proyecto.
